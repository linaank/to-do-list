# To-Do лист
Лабораторная работа №2 по дисциплине "Веб-программирование". ИСУ: 474301

To-Do лист в тематике пиксели + коты.

**Деплой:** https://linaank.github.io/to-do-list/

## Возможности листа

- Добавление задач с названием и датой
- Редактирование текста, даты задачи
- Удаление задач
- Отметка задачи как выполненной
- Сортировка по дате (сначала старые / сначала новые)
- Фильтрация по статусу (все / выполненные / невыполненные)
- Поиск по названию
- Изменение порядка задач с помощью drag-and-drop (кастомная фильтрация)
- Сохранение задач в `localStorage`, после перезагрузки страницы они оне теряются
- Адаптивная вёрстка для телефонов и планшетов

## Технологии

- HTML, CSS, JavaScript (без фреймворков и библиотек)
- Вся структура страницы создаётся динамически через DOM API
- Пиксельный котик рисуется в JS через SVG
- Шрифт [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P)

## Если хочется запустить локально

```bash
git clone https://github.com/linaank/to-do-list.git
cd to-do-list
```

Затем открыть `index.html` в браузере. !Для шрифта нужен интернет!
